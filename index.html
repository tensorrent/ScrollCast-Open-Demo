01 THE IDEA

Send the film.
Keep the invitation.

A link moves a file. Scrollcast separates the sealed film from permission to watch it—so a screener can reach the right people, on your terms.

01 / SEAL

The film travels sealed.

Encrypted media. A separately shared key. The film alone grants no access.

02 / INVITE

You set the terms.

03 / VERIFY

Trust is checked.

The player checks the publisher and each segment. Altered bytes cause a visible halt before decode.

The protection has a boundary.

A granted session cannot be taken back, and no system prevents a camera pointed at a screen. Scrollcast is not a replacement for DCP/KDM, Widevine, or FairPlay.

What this browser demo can and cannot enforce +

The sample above verifies the publisher signature and both segment addresses before decode. Your own file is encrypted and signed with a new key in this tab. The sender preview shows the original file while ciphertext verification runs; a recipient’s file is verified and decrypted before it is displayed.

Viewing terms are signed into the container, but a browser-only page cannot enforce them across devices. “1 open” is stored in this browser and can be reset. Different software can ignore the terms. Real ticket counting and cancellation require the hosted access server.

This page does not transcode. Use a short clip in a format your browser can play, or a JPEG/PNG image. Keep the access code: it is not included in the sealed file and cannot be recovered from it.
